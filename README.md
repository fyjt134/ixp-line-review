# IX专线测评：MKCloud 四条 IXP 专线怎么选，前置条件、套餐价格与避坑点一次讲清

搜「IX 专线测评」的人，大概率已经听过这种说法：拿一台阿里云或腾讯云的服务器做前置，通过互联网交换中心（IXP）连到境外出口，延迟比公网直连稳，价格又比传统 IEPL/IPLC 便宜一大截。听起来很美，但真到选购这一步，问题就来了：IX 专线到底和 IPLC 差在哪？哪些云厂商能当前置？一两百块的入门款是不是够用？这篇文章以 MKCloud（mkcloud）在售的 IXP 专线产品线为样本，把这些问题逐个拆开讲。

## 先说结论：IX 专线是什么，别和 VPS 混为一谈

IX 专线简单说，就是基于 BGP 对等互联（Peering）、经互联网交换中心（IXP）直连的跨境链路。你的流量从云厂商内网进入交换中心，再从境外出口 IP 出去，中间不经过公网。

它的和 IPLC、IEPL 的差别，用一句不太严谨但好懂的话概括：IPLC 是点对点的物理专线，IEPL 是二层以太网专线，而 IX 是大家在交换中心里「拼桌」——各家网络在 IXP 里互相宣告路由，谁都能连谁。NodeSeek 上有一篇科普帖专门吐槽过这种误解：很多人拿 IX 和 VPS 比带宽比流量，然后得出「IX 流量带宽小还要前置」的结论，但这两类产品根本不是一回事。IX 卖的是跨境路径，VPS 卖的是计算资源。

对普通用户来说，IX 的实际意义是：**价格比物理专线低不少，但你需要自己有一台跑在支持 IXP 互联的云厂商上的前置服务器**。这是它和传统专线最本质的使用差异，也是后文所有选购判断的前提。

## 测评前必须搞懂的一件事：前置条件

MKCloud 的 IXP 产品在购物车页面写得非常直白：入口 IP 只在 IXP 内宣告，仅允许云厂 BGP 网络连入，需要云厂 BGP 网络作为前置搭配使用。

具体到上海入口，目前支持的前置包括：

- 阿里云国内全网
- 腾讯云国内全网
- 百度云国内全网
- 火山云华东
- 华为云华东
- UCloud 华东

深港方向的入口则偏向华南：腾讯云、百度云国内全网，火山云华南、华为云华南等（上海入口的阿里云在深港线路上标注「暂时不通」）。

这意味着什么？意味着如果你手里没有这些云的国内服务器，买之前要先把前置成本算进去。linux.do 上关于 IX 云厂互联的讨论里，不少人的共识是：IX 本身门槛不高，真正的门槛反而是找到好用、便宜、带宽有保证的前置——阿里、腾讯的轻量服务器便宜，但没有带宽保证，已经出现过被限速到 20M 甚至 1M 的案例。

换句话说，IX 专线的总成本 = 专线月费 + 前置服务器费用。只看前者做预算，容易失算。

## MKCloud 的 IXP 产品线：四个方向

MKCloud 是 2023 年成立的国内专线服务商，主打合规跨境电商专线，产品线覆盖 IEPL、IPLC 和 IX 三类。其 IXP 专线目前有四条线路，对应三个主流出海方向：

- **深港 IX**：华南入口，香港 BGP 出口，端内延迟 1~2ms
- **沪港 IX**：上海入口（云厂优化网络通道），香港 BGP 出口，端内延迟 1~2ms
- **沪日 IX**：上海入口，日本 BGP 出口，端内延迟 25~28ms
- **沪美 IX**：上海入口，美国 BGP 出口，端内延迟 124~134ms

四条线路都是流量计费（共享带宽）模式起步，也可以选独享带宽计费。每台 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP，共两个独享 IPv4。所有套餐标注「超量停机」，超量后可自助购买流量重置或提交工单补差价升级。

有一点要提前说清楚：官网标注的「端内延迟」指的是专线内部的延迟，不是你从家里到目标网站的全程延迟。全程延迟还要加上你到前置服务器、以及出口到目标服务器的两段。

## 购买前必须知道的五件事

这几条全部来自官网购物车页面和知识库的明文提示，属于买之前不看、出事后没地方说理的类型：

1. **需要中国身份实名**。所有产品需遵守中国法律，需中国身份信息实名，仅限个人或企业正规用途。
2. **禁止机场、回国等用途**。官网明确写着「禁止机场、回国等违法违规用途，一经发现立刻清退不退款」。MKCloud 不是机场，是给跨境电商、独立站这类正规业务用的跨境 VPS。
3. **省级白名单**。直连款产品仅允许你设置的省份 IP 连入，省份可以随时切换，但异地团队要先核对接入限制。
4. **退款政策很严格**。仅支持质量问题退款，且需要提供准确具体的延迟、速度数据来证明是产品服务质量问题；服务开通后不支持更换到其他地域。
5. **只支持支付宝付款**。目前官网只支持支付宝，暂无其他支付方式。

优惠方面，官网不定期在知识库发布活动，历史上的流量计费产品循环折扣、独享带宽首月折扣等优惠码都是活动期限定，过期即失效。目前购物车的优惠券栏需要登录后才能看到准确信息，下单前建议先登录核对，也可以直接 [👉 前往 MKCloud 商店查看当前优惠](https://bit.ly/MKCLoud)。

## 几个常见问题

**已经有阿里云、腾讯云服务器，就能直接用 IX 吗？**

不一定。要核对云厂、地域和网络条件：沪日、沪美线路要求火山云华东、华为云华东、UCloud 华东这类华东节点，沪港线路还标注阿里云暂时不通。品牌对不代表地域对，下单前以购物车页面的支持列表为准。

**IX 专线可以用来做对外网站吗？**

不行。官方知识库明确说明：产品出口不支持外部连入，主要用于在 VPS 内向外访问业务。公开站点、支付回调、对外游戏服务需要另选支持入站的产品。

**超量之后会怎样？**

当前计量型套餐按上行、下行双向统计，超量后停机（不是限速），可自助购买流量重置或提交工单补差价升级。预售期那种「超量限速 10Mbps」是历史规则，现售产品不适用。

**IK 专线的延迟到底怎么算？**

官方给的端内延迟只是专线内部那一段。你的完整路径是：本地宽带 → 前置云服务器 → IXP 专线 → 境外出口 → 目标服务器，全程延迟要自己端到端测。官网知识库也提示，ping/mtr 只能辅助观察，带宽测试需要在自有或授权的服务端进行。
